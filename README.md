# 하늘끝 탑 3D

10층 블록 탑을 꼭대기까지 올라가는 3D 웹 게임입니다. 브라우저만 있으면 설치 없이 플레이할 수 있습니다.

**▶ [플레이하기](https://jhleebre.github.io/sky-tower/)**

## 게임 규칙

- 층마다 새로운 블록이나 함정이 하나씩 나옵니다.
- 깃발 바닥에 도착하면 아래 구멍이 메워져서, 그 층에서 떨어져도 깃발 바닥에 떨어집니다.
- 정상에 도착하면 걸린 시간과 아웃 횟수가 기록됩니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `←` `→` 또는 `A` `D` | 몸 방향 돌리기 |
| `↑` `↓` 또는 `W` `S` | 앞으로 / 뒤로 |
| `스페이스` | 점프 |
| `V` | 시점 바꾸기 (1인칭 · 어깨 · 멀리) |
| `M` | 소리 켜기/끄기 |
| `Esc` 또는 `P` | 메뉴 |

터치 기기에서는 왼쪽 버튼으로 이동과 방향 전환을, 오른쪽 버튼으로 점프를, 위쪽 버튼으로 시점 전환을 합니다.

## 난이도

- **쉬움**: 틈이 좁고 발판이 넓으며, 함정이 느립니다.
- **보통**: 틈이 넓고 함정이 빠릅니다.
- **어려움**: 보통과 같은 탑이지만 아래층 구멍이 메워지지 않습니다.

## 로컬 실행

빌드 과정은 없지만, 코드가 ES 모듈로 나뉘어 있어서 `index.html`을 파일로 바로 열면 동작하지 않습니다. 프로젝트 폴더에서 로컬 서버를 띄운 뒤 브라우저로 접속하세요.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000` 을 엽니다. GitHub Pages 같은 정적 호스팅에는 그대로 올리면 됩니다. [three.js](https://threejs.org/)(r128)와 Google Fonts를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 폴더 구조

```
index.html              화면 마크업과 모듈 진입점
css/style.css           HUD · 메뉴 · 터치 버튼 스타일
src/
  main.js               초기화와 프레임 루프
  game.js               게임 흐름 (메뉴/플레이/일시정지/정상 도착), 난이도, 입력 → 시뮬레이션
  config.js             물리 상수, 난이도별 설정
  data/
    stages.js           10개 층 (이름, 하늘색, 블록, 등장 요소)과 난이도별 탑 모양 규칙
  world/                ← three.js·DOM을 쓰지 않는 순수 로직
    ring.js             기둥을 둘러싼 고리 좌표 계산
    generator.js        시드 기반 탑 생성 (블록, 함정, 층 바닥, 이동 경로)
    tower.js            생성된 탑 + 조회용 표
    sim.js              플레이어 물리, 움직이는 블록 · 가시 · 불덩이, 깃발과 구멍 메우기
  render/
    renderer.js         렌더러, 장면, 카메라, 조명, 해 그림자
    textures.js         캔버스로 그리는 16x16 픽셀 텍스처
    materials.js        재질과 공용 도형
    blockGeo.js         블록 모서리 음영(앰비언트 오클루전)을 구운 블록 · 바닥 도형
    scenery.js          그라데이션 하늘, 먼 산, 구름 바다, 별, 높이 따라 바뀌는 안개
    towerMesh.js        탑 메시, 시뮬레이션과 동기화, 가리는 블록 반투명 처리
    player.js           캐릭터 모델, 착지 찌그러짐, 발밑 그림자
    cameraRig.js        시점 3가지 (1인칭 · 어깨 · 멀리)
    effects.js          조각 파티클 (착지 먼지, 젤리 튕김, 깃발 반짝임, 불꽃놀이)
  audio/sound.js        WebAudio로 합성하는 효과음
  ui/hud.js             HUD, 배너, 시작 · 일시정지 · 결과 카드
  ui/input.js           키보드 · 터치 입력
  util/                 rng.js (시드 난수), storage.js (기록 · 설정 저장)
  dev/
    planner.js          탑을 끝까지 오르는 입력을 찾는 탐색 봇
    autoplay.js         봇이 찾은 입력으로 실제 게임을 자동 플레이 (QA용)
tools/
  tower-check.js        탑 모양이 그대로인지, 모든 난이도를 끝까지 오를 수 있는지 확인
  check-tower.html      브라우저에서 확인 (로컬 서버로 열기)
  check-tower.mjs       Node에서 확인 (`npm test`)
```

이미지·소리 파일은 없습니다. 텍스처는 `render/textures.js`에서 캔버스로 그리고, 소리는 `audio/sound.js`에서 합성합니다.

## 그래픽과 소리

- **그림자**: 해 방향 그림자가 캐릭터와 블록에 생깁니다. 발밑 그림자도 함께 있어서 점프 거리를 가늠하기 쉽습니다.
- **블록 모서리 음영**: 블록끼리 맞닿은 모서리와 바닥을 살짝 어둡게 해서 덩어리감을 줍니다. 탑을 만들 때 한 번 계산해 둡니다.
- **하늘과 원경**: 층마다 하늘 그라데이션이 바뀌고, 먼 산과 두 겹의 구름 바다를 지나 올라가면 밤하늘과 별이 나옵니다. 높이 올라갈수록 안개가 옅어져 멀리까지 보입니다.
- **효과음과 이펙트**: 점프, 착지(세기에 따라 다름), 발소리, 젤리 튕김, 깃발 도착, 가시, 불덩이, 아웃, 정상 도착에 소리와 이펙트가 있습니다. 함정 소리는 가까울수록 크게 들립니다.

## 탑 수정하기

1. 층 구성은 `src/data/stages.js`, 블록 배치 규칙은 `src/world/generator.js`, 움직임은 `src/config.js`와 `src/world/sim.js`에서 바꿉니다.
2. 바꾼 뒤에는 로컬 서버에서 `http://localhost:8000/tools/check-tower.html` 을 열거나, Node가 있다면 `npm test` 를 실행합니다. 탑 모양이 바뀌었는지(지문 비교), 그리고 봇이 세 난이도 모두 한 번도 떨어지지 않고 꼭대기까지 오를 수 있는지 확인합니다.
3. 탑 모양을 일부러 바꿨다면 `tools/tower-check.js`의 `LAYOUT_HASH`를 새 값으로 고칩니다.

## 자동 플레이 (QA)

주소 뒤에 `?autoplay`를 붙이면 봇이 실제 게임으로 1층부터 꼭대기까지 올라갑니다. 봇은 층마다 먼저 오를 수 있는 입력을 계산하고(플레이보다 앞서 조금씩 계산하므로 화면이 멈추지 않습니다), 게임은 그 입력을 그대로 재생합니다. 화면 아래 패널에 현재 층, 시간, 아웃 횟수와 봇이 누르는 키(↺ ▲ ↻ 점프)가 표시됩니다.

- `http://localhost:8000/?autoplay` : 마지막으로 고른 난이도로
- `http://localhost:8000/?autoplay=hard` : 난이도 지정 (`easy` · `normal` · `hard`)
- `http://localhost:8000/?autoplay=all` : 쉬움 → 보통 → 어려움을 차례로
- `&from=5` : 5층 깃발부터, `&speed=2` : 2배속 (최대 8)
- 자동 플레이 중에는 이동 키를 받지 않으며, `V`로 시점을 바꿀 수 있고 `Esc`로 멈추고 메뉴로 돌아갑니다. 자동 플레이 기록은 최고 기록에 저장되지 않습니다.
- 층이 바뀔 때마다 실제 게임 상태가 계획과 정확히 같은지 확인하고, 다르거나 봇이 떨어지면 패널에 실패로 표시합니다.
